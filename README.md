# Dataprojekt

Textile lifetime analysis: Exploring real-world industrial data from a Danish
workwear company.

## Branches

**Main Branch**  
**Levetids modelering**  
**Proof of concept**

## Main Branch indhold
**Dataprojekt kontrakt:**  
Indeholder en samarbejdskontrakt mellem gruppemedlemmer, der sikrer det bedst mulige gruppemiljø.

**Anbefalinger til virksomheden:**  
Indeholder vores endelige anbefalinger til, hvordan data bør indsamles og behandles fra virksomhedens side i fremtiden, med henblik på at muliggøre mere fyldestgørende og dybdegående analyser samt mere konkrete resultater.

**Project Decriptions:**  
Indeholder følgende:
1. Titlen på projektet, navne på gruppemedlemmer og en figur, der illustrativt viser vores projekt.
2. Et klart og let forståeligt overblik over de interessante hovedproblemer i projektet.
3. Eksempler på data brugt i projektet med tilhørende deskriptiv statistik.
4. Beskrivelse af, hvor vi nåede til, og hvad vi ville ønske, vi kunne have gjort.

**Dataloader:**  
Program brugt til at indhente og sortere dataen.

**Folder Data:**  
Indeholder alt data, som virksomheden, projektet omhandler, har stillet til rådighed for Dataprojektet.

**Indledende Dataanalyse:**  
Indeholder de indledende dataanalyser lavet i første del af projektet. Ofte første udkast til de endelige modeller.

**Dataanalyse:**  
Indeholder analyser brugt i vores histogram app og analyser brugt til at udforske mulige sammenhænge.

**2D Histogram:**  
Indeholder visualiserings-værktøjet og de filer, den skal bruge til at visualisere datasættet 'PLC, product detaljeret, Aarhus'.
